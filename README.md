# 조선유랑기 (朝鮮流浪記)

조선 후기(19세기)를 배경으로 한 횡스크롤 RPG 웹게임입니다.
양반·중인·상민·천민 가운데 하나를 골라 한양 장터와 인왕산을 누비며
NPC의 부탁(퀘스트)을 해결하고, 퀘스트마다 나오는 **📜 역사 노트**로 조선 후기 사회를 배웁니다.

제작: 역사교사 최경환

## 이야기 구성
- **1장 · 상품 화폐 경제가 발달하다** — 서당 훈장(실학), 주모(산적과 삼정), 은광 주인(은광의 산군 · 광업의 발달), 보부상·시전·난전·유기장·공인·김만덕(💬 역사 이야기)
- **2장 · 삼정의 문란 (남원 고을)** — 훈장의 편지 → 김 노인(삼정이란?) → 전정: 거짓 토지 장부 모으기 / 군정: 탐관오리 혼내기 → 환곡: 동헌의 변 사또 → 암행어사 출두
- **3장 · 들고일어난 백성들** — 훈장의 역사 두루마리 → 1811년 평안도 정주(세도 정치, 홍경래의 격문, 흉년) → 1862년 경상도 진주(유계춘, 초군, 빚 문서 도깨비, 곳간 도깨비) → 임술 농민 봉기와 삼정이정청
- **4장 · 흔들리는 신분제 (경상도 대구 향촌)** — 호적 대장으로 본 신분 구성 변화(1690~1858 그래프), 권반·향반·잔반·신향·역관(중인)·서얼·도망 노비와의 대화, 향전, 추노꾼, 보스 '신분의 벽'
- **5장 · 세도 정치의 그늘 (창덕궁)** — 경복궁이 폐허였던 시기 법궁 역할을 한 창덕궁(돈화문·금천교·인정전·청기와 선정전·희정당·후원 부용지·주합루), 철종 임금(실존 인물)·늙은 상궁·비변사 서리와의 대화, 매관매직과 과거제 문란, 보스 '세도 대감'(세도 가문 권세가를 나타낸 가상 인물)
- 게임 중 **M 키** 또는 오른쪽 위 버튼으로 조선 지도(삼남, 사건 위치, 현재 위치)를 볼 수 있습니다.

## 역사 퀴즈와 장터 사람들
- 퀘스트를 주는 NPC는 부탁하기 전에 **역사 퀴즈**를 냅니다(4지선다, 틀리면 힌트 후 다시 풀기, 맞힌 퀴즈는 저장).
- 한양 장터에는 퀘스트 없이 이야기로 역사를 알려 주는 사람들(💬)이 있습니다: 시전 상인, 난전 상인, 객주, 여각, **채제공**·**김만덕**(실존 인물).
- 각 장을 마치고 다음 장으로 넘어갈 때(포탈·두루마리) **장 복습 퀴즈**가 나옵니다. 장마다 3문제(객관식·주관식) 중 1문제가 무작위로 나오고, 틀리면 힌트를 보고 다른 문제로 다시 도전합니다. (`CHECKPOINTS`)
- 퀴즈는 `index.html`의 `QUIZZES`, 장터 사람들의 이야기는 `TALKS`에서 고칠 수 있습니다.

## 조작법
| 키 | 동작 |
|---|---|
| ← → | 이동 |
| Space | 점프 (공중에서 한 번 더: 빙글 도는 이단 점프 / ↓ + Space: 발판 아래로) |
| Z | 공격 (누르고 있으면 연속 공격) |
| X | 직업 기술 |
| ↑ / Enter | NPC와 대화 · 포탈 이동 |
| A | 국밥 먹기 (체력 회복) |
| M | 조선 지도 열기/닫기 |
| N | 역사 노트 보관함 (모은 노트 다시 읽기) |
| K | 몬스터 도감 |
| G | 다음 할 일 도우미 (모바일: 왼쪽 위 ❓ 버튼) |
| B (모바일: 한양 귀환 버튼) | 한양 장터로 바로 귀환 |
| V | 배경 음악 켜기/끄기 |
| H | 조작법 보기 |

모바일(가로 화면)에서는 화면에 터치 버튼이 나타납니다.

## 저장 방식
- 처음 화면에서 **학번 · 이름 · 닉네임**을 입력합니다. 다음에 같은 학번과 이름으로 들어오면 저장된 기록을 이어서 할 수 있습니다.
- 기록은 항상 **이 기기(브라우저)** 에 저장되고, 첫 화면에 "이 기기에 저장된 기록" 버튼으로 나타납니다.
- `index.html` 맨 위 `SAVE_URL`에 구글 앱스 스크립트 주소를 넣으면 **구글 시트**에도 저장됩니다. 이렇게 하면 다른 컴퓨터에서도 이어서 할 수 있고, 선생님은 시트에서 학생별 레벨과 진행도를 볼 수 있습니다.

### 구글 시트 저장 서버 설정
1. 구글 드라이브에서 새 스프레드시트를 만듭니다. (이름 예: `조선유랑기 저장`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 코드를 지우고 [`gas/Code.gs`](gas/Code.gs)의 내용을 붙여 넣은 뒤 저장합니다.
4. **배포 → 새 배포 → 유형: 웹 앱**을 선택하고 다음처럼 설정합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. 권한을 승인하면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. `index.html` 맨 위의 `const SAVE_URL = '';` 따옴표 안에 붙여 넣고 저장소에 다시 올립니다.

> 학번과 이름만으로 기록을 찾기 때문에, 다른 학생의 학번과 이름을 알면 그 기록을 불러올 수 있습니다. 수업용 게임이라 간단하게 만든 방식입니다.
